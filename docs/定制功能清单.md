# Solua 定制功能清单

2026-10-07 本地源码整理。此清单说明版本控制范围，不代表本次已部署或已验收生产。

| 功能 | 主要源码 | 当前内容 |
|---|---|---|
| 批发单据工具 | `solua_home/api/sales.py`、`api/child_items.py`、`public/js/wholesale_forms*` | 表格上传、粘贴货号和数量、批量选料和改数量、原生物料详情、门店建议、行备注同步 |
| 打印与导出 | `api/export.py`、`api/print_data.py`、`printing/`、`print_format/` | 客户货号合并、Excel 列宽、数量格式、PDF 图片压缩和页边距、单张及批量导出、显式读取最新打印数据 |
| A4 设计器 | `api/a4_designer.py`、`printing/a4_designer.py`、`public/js/a4_print_designer*` | 标题、Logo、补充说明、SPU、颜色和明细显示选项 |
| 库存与商品 | `api/stock.py`、`api/variants.py`、`item_metrics.py`、`receipt_cost_sync.py`、`quantity_precision.py` | 销售单位显示、整数数量、退货数量校验、入库参考成本同步及取消恢复、变体条码和色卡 |
| 收款与价格差额 | `cash_discount.py`、`api/price_difference.py`、`invoice_stock_guard.py` | 现金折扣钩子、价格差额明细、关联交货单时防止销售单重复扣库存 |
| 首页与报表 | `api/home.py`、`api/unbilled.py`、`api/workspace.py`、`solua_wholesale/report/` | 首页库存显示、按单据数量识别待开票、价格差额独立展示、商品销售历史和库存树 |
| xPos 数量显示 | `xpos-client/frontend/src/utils/numberFormat.ts` | 默认显示整数；指定精度时保留小数 |

上表中的 `solua_home/` 路径均相对于 `my_custom_app_example/`。注册入口为 `hooks.py`，字段和迁移入口为 `install.py`、`patches.txt`。

## 表单加载入口

Sales Order、Delivery Note、Pick List 的本地入口为 `wholesale_forms_additional_notes_loader_v17.js`，实际加载 `wholesale_forms_stock_entry_v20261006.js?v=stock-entry-tools-20261006a`。旧文件保留，便于追溯；发布前必须回读生产实际入口。

## 本地验证

- 各功能沿用 `my_custom_app_example/solua_home/tests/` 中的 Python 和 Node 检查；Python 使用 `-B`。
- `whatsapp_check.py` 运行时将 `my_custom_app_example` 加入 `PYTHONPATH`。
- xPos 检查使用 `vitest run tests/numberFormat.spec.ts`。
- `receipt_cost_sync_production_check.py` 和 `readonly_candidate_check.ps1` 需要生产环境，本次整理不执行。
- 本地检查不能替代生产文件、运行时 hooks、实际资源及页面/API 回读。

## 保留在本地的内容

`.tmp/`、`tmp/`、`artifacts/`、`output/`、`outputs/`、根目录 `tmp_*.py` 和 `xpos-client/xpos/` 的未跟踪产物由 `.gitignore` 排除，文件不删除。已经跟踪的历史文件不自动移出 Git。

管理员移动端的配送、路线和定位功能仍在其他任务中编辑。`api/mobile*.py`、`www/mobile/`、`public/mobile/`、`tests/mobile_*` 及定位字段迁移保留为未提交改动，待该任务完成后单独验证和提交。
