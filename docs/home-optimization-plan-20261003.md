# Solua 首页优化与验收计划

执行：Luna；审查、生产发布与验收：主任务。

按以下顺序实现，完成后作为一次范围明确的发布批次上线。

| 顺序 | 项目 | 验收条件 |
| --- | --- | --- |
| 1 | 批发导航与中文报表 | 首页明确入口可进入批发侧栏；经营金额、送货汇总、库存树入口显示中文；收银员保留 POS 模式。 |
| 2 | 待开票客户 | 展示全部历史待开票交货，不受金额卡片的期间影响；客户、剩余商品金额、交货天数和草稿状态可见；原生生成未保存发票，已有草稿直接查看。 |
| 3 | 发票草稿待办 | 已保存草稿可从首页继续处理；显示数量及全部入口；不自动保存、提交或重复建单。 |
| 4 | 空状态 | 无逾期、无采购待收货、未设置库存阈值、无权限、数据不完整、加载失败分别说明。 |
| 5 | 完整待办 | 明细前五条标明完整数量并可查看全部；订单交期和剩余量、应收到期日和逾期天数可见。 |
| 6 | 时间范围与口径 | 默认保留各指标独立偏好；可主动统一时间范围；自定义起止日期有效；切换指标保留所选期间；已付按期间发票结清金额。 |
| 7 | 商品与库存查询 | 产品名称和颜色不会重复显示；展示当前仓库的实际、预留、可用数量；模板与变体区分；无权限不显示虚假零库存。 |
| 8 | 常用操作 | 顶部可直接新建订单、按订单交货、处理待开票、收款和查询库存；复用现有入口及权限。 |

发布边界：只修改 Solua 自定义应用的相关 API、首页、报告与翻译，不修改 ERPNext/Frappe 核心；保留本地及生产其他改动。手工回滚副本放在 private/deployment_snapshots/，Bench 备份目录仅放 Bench 生成的文件。

验证：适当的已有检查与关键权限/金额/时间范围回归；比对生产源文件、接口实际结果、中文翻译运行时及登录页面。验收不保存或提交业务单据，不更改实际库存阈值。
